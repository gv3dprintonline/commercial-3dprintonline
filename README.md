# GV3D Print Easy Edit

### Change products, prices and images without editing the website design

**Products:** edit `products.js`

Example:
```js
{name:"Keychain",price:"₹99",category:"Gifts",description:"Custom keychain.",image:"images/keychain.jpg"}
```

**Images:** put product photos in the `images` folder and use their filename in `products.js`.

**WhatsApp + Google Form:** edit the first two settings in `script.js`.

Upload/replace these files in GitHub Pages:
- `index.html`
- `style.css`
- `script.js`
- `products.js`
- `images/`

You do not normally need to edit `index.html` or `style.css`.
